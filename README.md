# Tale Engine

A Telltale-style narrative game runtime for Godot 4.6: walk-around hubs, conversations with timed choices, playable action scenes, story state that later scenes read, checkpoints and rewind. An episode is data. Adding scenes, lines, choices and fights needs no engine code.

Everything on screen is a greybox placeholder. Characters are capsules, sets are boxes, and no line is voiced. Real characters, sets and voice plug in without changing the engine; see [docs/ASSET_SWAP.md](docs/ASSET_SWAP.md).

## Run it

Open `project.godot` in Godot 4.6 and run. Choose New game.

| Where | Keyboard | Gamepad |
|---|---|---|
| Walking | WASD move, E interact | Left stick, A |
| Conversation | 1-4 choose, Space skip a line | Y / B / A / X, A |
| Action prompts | Space, J, K, W, S as shown | A, X, B, D-pad |
| Any time | Escape pause, F3 debug panel | Start |

Episode 0 is about three minutes: a bar, a stranger, a fight that changes with what you said and noticed, and an alley chase if it goes badly.

## What is here

| Folder | What it is |
|---|---|
| `addons/tale_engine` | The narrative runtime: story state, episode graph, dialogue balloon, cast, hubs, saves, validator. |
| `addons/cinematic_action_director` | The action layer: timelines with timed inputs and branching. Works on its own. |
| `addons/dialogue_manager` | Dialogue Manager 4.2.0 (MIT), vendored unmodified. |
| `content/episode_0` | The placeholder episode: step graph, dialogue, cast, two locations, two encounters. |
| `tests` | Headless suites, the autoplayer, and scenes for validating and recording. |
| `docs` | Authoring, asset swap, action-layer reference, and the earlier research. |

## Check it

```bash
godot --headless --editor --path . --import
godot --headless --path . res://tests/run.tscn          # 99 checks, 7 suites
godot --headless --path . res://tests/validate.tscn     # problems in the episode data
```

`run.tscn` takes suite names after `--` to run a subset: `-- flow save`. Two warnings about invalid sequences in the `cad` suite are expected.

To record a playthrough, with a display:

```bash
godot --path . --write-movie out.avi --fixed-fps 30 res://tests/record.tscn
```

## Limits

- No real controller has been tested. The tests inject gamepad events.
- Lip-sync and facial animation are not built. `TEActor.speak()` is where they attach.
- Fights are only as convincing as their animation. Paired contact clips are content work.
- One save slot is wired to the menu. The save code takes any slot number.
- The stage scenes were generated by a script that is not in the repository. Edit them in Godot's animation panel.
- `docs/research/05` describes an earlier prototype that is not in this repository.
