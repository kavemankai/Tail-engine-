# Halogen: Cyberpunk Bar Environment (Godot 4.6.3)

Work-in-progress snapshot. Open `project.godot` in Godot 4.6.3 (Forward+). First open re-imports textures (~10 s).

- `scenes/BarInteriorEnvironment.tscn`: reusable environment scene (no NPCs, no game logic)
- `scenes/BarEnvironmentPreview.tscn`: main scene. Capsule test mannequin plus controls:
  WASD move, mouse look (click to capture), 1-7 cinematic camera markers, 0 player cam,
  E door open/close, L lock/unlock, P service panel cover, G/H panel LEDs, Q quality preset, F3 stats.
  Benchmark: run with `-- --benchmark` (writes `user://benchmark.txt`).

Key nodes (relative to the environment root):
- `Anchors/NPC/*`, `Anchors/Interaction/*`, `Anchors/Cameras/*` (Marker3D; camera markers carry `fov` metadata)
- `Interactive/RestrictedDoor` (BarSecurityDoor: open(), close(), toggle(), set_locked())
- `Interactive/ServicePanel` (BarServicePanel: open_cover(), close_cover(), set_indicator(&"amber"/&"green", on))
- `NavigationRegion3D` (pre-baked, cell size 0.1; set `navigation/3d/default_cell_size` = 0.1 in the host project or rebake)
- Root script `BarEnvironmentController`: effect toggles + `apply_quality_preset("high"/"medium"/"low")`

All textures, signage, ads and audio are original, generated by `scripts/tools/gen_textures.py` and `gen_audio.py`.
The whole scene is regenerated by `godot --headless --path . --script res://scripts/tools/build_bar.gd`.
Collision: environment on layer 1; interaction areas on layer 8 (ray-pickable only).
