# Optional prototype assets

The imported humanoids, animations, Halogen environment and stool are exploratory assets. They are not required by Tail Engine, do not establish the final visual direction, and may be replaced, removed or abandoned. The current Episode 0 cast and bar scene reference them for evaluation; a project can keep the engine and use entirely different characters, environments and props. No decision to ship these assets is implied.

The humanoid kit and narrative characters came from the supplied TheStatic-Humanoid-Source.zip. The kit's source and licence notices are retained in `addons/humanoid_kit/licenses/`. The user identified the supplied bar environment as their own creation. Its original package notes are retained in `docs/SUPPLIED_BAR_README.md` and `docs/ASSET_AND_LICENSE_REGISTRY.md`; those historical notes recorded that no explicit licence was included. The original bar scene remains at `scenes/BarInteriorEnvironment.tscn`; the Tail Engine-specific stool-free copy is `examples/last_call/humanoid/halogen_no_stools.tscn`.

The current integration is a prototype. Movement and QTE dispatch were demonstrated; substitute clips are not matched contact choreography. The stool hotspot and stage animation path are preserved. Full environment route regression, controller acceptance, audible voice mix, collision/camera staging and production animation remain open. The existing QTE target/cinematic fixture cast is separate. The bar was authored for Forward+ and currently emits unsupported-effect warnings under the Compatibility renderer.

To abandon this entire prototype on a clean working tree, revert the commit that introduced it (`git revert <prototype-commit>`), resolving conflicts if subsequent changes overlap. This preserves subsequent history. To replace only part, remove or replace the `actor_scene` references in `examples/last_call/episode_0/cast.tres` (an empty value uses the original placeholder), or substitute another set under `examples/last_call/episode_0/locations/bar.tscn`, and replace the stool mesh in `examples/last_call/episode_0/encounters/bar_fight/stage.tscn`. Keep the required location marks, hubs, camera names and stage `Stool` node until their consumers and animation tracks are updated. Do not delete the imported directories while any scenes still reference them. See `docs/ASSET_SWAP.md` for the actor contract and scene swap guidance.
