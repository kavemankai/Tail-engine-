# Roadmap

The goal is an engine a real game can be built and released on, for Windows and Steam Deck.

- [STATUS.md](STATUS.md) lists what is done and what is left, phase by phase.
- [MECHANICS_TO_TEST.md](MECHANICS_TO_TEST.md) lists every mechanic and whether it works today.

The documents in `research/` describe earlier experiments. Their phase numbers and estimates are historical.
