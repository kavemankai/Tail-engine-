# Included third-party material

- Dialogue Manager 4.1.0, commit `a719088aea342572f29b5559fd8726896c9519b2`, retrieved 15 November 2026, https://github.com/nathanhoad/godot_dialogue_manager, MIT. Licence is in `addons/dialogue_manager/LICENSE`. The stock example balloon script is locally modified to remove its example warning. The Dialogue Manager runtime duplicates compiled line data before attaching its resource; this fixes a reference cycle observed in the prototype tests.
- Existing local Godot Humanoid Kit addon from `Godot-Humanoid-Kit-Addon.zip`, extracted 15 November 2026. Its included `addons/humanoid_kit/licenses/ASSET_SOURCES.md` records the Quaternius CC0 models and animation sources, source checksums, and local processing. The source notices are in the same folder. The archive's original acquisition date was not established in this session.
- User-supplied `CyberpunkBarEnvironment.zip`, SHA-256 `21a318fb7c57aed0e5aeeca6f5e67a20b20ac71f00efa69f048b3065a5af2a0c`. Imported 15 November 2026 into `assets/`, `scripts/environment/` and `scenes/BarInteriorEnvironment.tscn`. The archive README describes its textures, signage, ads and audio as original and generated; no explicit licence or separate rights notice was present. The user authorised integration into this project. Wider redistribution or commercial rights have not been established. The supplied README is retained as `docs/SUPPLIED_BAR_README.md`.
- Simple environment geometry and project scripts were generated for this prototype. Research checkouts in `_research` are separate and not shipped as active addons.

- User-supplied Narrative Characters addon, integrated 16 November 2026 from `Narrative-Characters-Addon.zip`. Its documentation identifies Quaternius CC0 body and animation sources via the unchanged Humanoid Kit; clothing, profiles, and procedural conversation layer were created in the supplied package. See `docs/SOURCES_AND_LICENSES.md` and the kit notices.
